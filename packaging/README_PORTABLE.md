# Storage Box Launcher

这是 Windows 便携版。解压后直接运行：

```text
StorageBoxLauncher.exe
```

## 使用方式

- 左键点击盒子：展开 3x3 项目面板
- 拖动盒子：移动位置
- 拖动盒子边缘/角落：调整大小
- 右键盒子：添加文件/应用、添加文件夹、重命名、调整外观、新建盒子、删除盒子、切换置顶、开机自启动、退出
- 双击盒子：添加文件/应用
- 拖入应用、文件夹、文档、快捷方式或脚本：收纳到盒子中
- 在九宫格内拖动项目：调整顺序
- 右键盒子 `外观`：切换主题色或选择图片作为盒子图标

## 开机启动

推荐在托盘菜单或盒子右键菜单中勾选 `开机自启动`。程序会自动在当前 Windows 用户的启动目录中创建或删除快捷方式。

## 配置和备份

配置会保存在当前 Windows 用户的应用数据目录中，通常是：

```text
%APPDATA%\StorageBoxProject\Storage Box Launcher\config.json
```

程序保存配置前会保留一份最近备份：

```text
config.backup.json
```

如果配置文件损坏，程序会保留一份带时间戳的坏文件副本，并恢复默认配置。
