# Storage Box Launcher v1.0.2

## 改进

- 新增 `设置...` 面板，可集中切换界面主题、置顶显示和开机自启动。
- 新增清透浅色、深色玻璃、暖砂柔光、极简白四套界面主题。
- 3x3 项目面板新增轻量淡入和缩放动画，打开与关闭更顺滑。
- 文件、文件夹或快捷方式目标丢失时，九宫格会显示暖色状态和感叹号标记。
- 开机启动流程减少同步保存动作，先显示盒子，再延后托盘初始化和必要配置保存。
- Windows exe 版本信息、产品名、原始文件名和版权信息随 CMake 版本号生成。
- 配置保存改为原子写入，并保留最近一次 `config.backup.json`。
- 配置损坏时会保留 `config.invalid.<timestamp>.json`，然后恢复默认配置。
- 托盘菜单和盒子右键菜单新增开机自启动、打开配置文件夹和设置入口。

## 下载

下载 `StorageBoxLauncher-v1.0.2-win64.zip`，解压后运行：

```text
StorageBoxLauncher.exe
```

同时提供 `.zip.sha256` 校验文件。
